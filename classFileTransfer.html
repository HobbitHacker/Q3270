FileTransfer::FileTransfer ( )

FileTransfer::FileTransfer - initialise the file transfer object.

The file transfer object is used to handle the IND$FILE structured fields. It is signalled when a file transfer is started, and processes the requests for reading or writing local files.

Parameters
reply- the reply buffer to send back to the host

This function processes the Close Req structured field. It closes the local file, and sends a Close Ack back to the host. If the transfer was a receive, it commits the file to disk.

◆ getData()

void FileTransfer::getData ( QByteArray & reply)

FileTransfer::getData - process the Get Req structured field.

Parameters
reply- the reply buffer to send back to the host

This function processes the Get Req structured field. It reads a block of data from the local file, and sends it back to the host. If the end of file is reached, it sends an EOF error.

If CRLF conversion is enabled, it converts LF to CRLF before sending the data.

Parameters
buffer- the incoming data buffer

This function processes the Insert Data structured field. It extracts the data from the buffer, writes it to the local file, and acknowledges the data. If the Insert Data is a message, it emits a signal with the message.

◆ insertReq()

void FileTransfer::insertReq ( )

FileTransfer::insertReq - process the Insert Req structured field.

This function is called when the Insert Req structured field is received. It does not do anything in Q3270, but is included as the protocol requires it. The Insert Req is followed by the Insert Data structured field, which contains the actual data
