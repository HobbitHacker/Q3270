void FileTransferProgress::reject ( )
slot

FileTransferProgress::reject - reject the file transfer.

Reject the file transfer. This is called when the user cancels the file transfer. The first time this is called, it emits a signal to cancel the transfer, which is when the user clicks the cancel button. The second time, it closes the dialog, which is when the user clicks the close button after the cancellation is complete.
